# GreenBank | Python FinTech App

GreenBank is a desktop banking prototype built as a 2nd-semester FinTech project. It features account management, balance transfers, transaction logging, and real-time spending analytics.

## 🚀 Features
- **User Authentication:** Login and account creation system.
- **Banking Operations:** Real-time deposits, withdrawals, and peer-to-peer transfers.
- **Data Analytics:** Interactive spending and balance trend charts powered by Matplotlib.
- **Custom UI:** Modern dark-mode interface built with CustomTkinter.

## 🛠️ Built With
- **Language:** Python
- **GUI Framework:** CustomTkinter
- **Data Processing:** Pandas
- **Visualization:** Matplotlib

## 📦 How to Run Locally
1. Clone or download this repository.
2. Install required libraries:
   ```bash
   pip install customtkinter pandas matplotlib
   python "green bank.py" 
   '''
